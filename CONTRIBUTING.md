# Contributing to unibrowse

First off, thank you for considering contributing to unibrowse! It's people like you that make unibrowse such a great tool.

## How Can I Contribute?

### Reporting Bugs
- Use the [GitHub issue tracker](https://github.com/WindowsRefundDay/unibrowse/issues) to report bugs.
- Include a clear, descriptive title and as much relevant information as possible.
- Provide a step-by-step reproduction of the issue.

### Proposing Enhancements
- Enhancement suggestions are tracked as GitHub issues.
- Explain the current behavior and what behavior you expect to see instead and why.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Style Guide

- We use [PEP 8](https://www.python.org/dev/peps/pep-0008/) for Python code.
- Use descriptive variable names and keep functions focused on a single task.
- Ensure your changes integrate naturally with the existing UI structure in `app.py`.

## Credits
This project utilizes `browser-harness` and `unibrowse` backends for stealth automation. Please ensure your contributions maintain compatibility with these core engines.
