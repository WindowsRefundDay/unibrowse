# unibrowse: Full Reconstruction Prompt

You are reconstructing **unibrowse** — a macOS dock-launchable PySide6 GUI that puts a stealth browser agent at your fingertips. The agent backend is OpenCode (with Antigravity auth), the browser automation layer is browser-harness (CDP), and the UI gives real-time activity feed, live screenshots, and tab management.

---

## What You're Building

```
User types natural language task
  → PySide6 GUI (app.py)
    → spawns: opencode run <prompt> --model google/gemini-3-flash --variant minimal
      → browser-harness tools (navigate, click, screenshot, tab management)
        → Chrome on port 9223 (stealth, BH_NO_ACTIVATE=1)
          → screenshot + tab state poll back to GUI every 3s
```

**Critical patches to apply after cloning:**

### `browser-harness/src/browser_harness/helpers.py`

The upstream `switch_tab()` uses exact targetId match. Replace with fuzzy matching (title/URL substring):

```python
def switch_tab(identifier):
    """Switch to a tab by targetId, title substring, or URL substring."""
    targets = cdp("Target.getTargets")["targetInfos"]
    match = None
    for t in targets:
        if t.get("targetId") == identifier:
            match = t
            break
    if not match:
        lower = identifier.lower()
        for t in targets:
            if lower in (t.get("title") or "").lower() or lower in (t.get("url") or "").lower():
                match = t
                break
    if not match:
        raise ValueError(f"No tab matching {identifier!r}")
    cdp("Target.activateTarget", targetId=match["targetId"])
    _state["target_id"] = match["targetId"]
    return match["targetId"]
```

### `browser-harness/src/browser_harness/_ipc.py`

Add `umask 0o077` when creating the Unix socket (upstream fix for socket permission security):

```python
# In the listener setup, before sock.bind():
old_umask = os.umask(0o077)
try:
    sock.bind(socket_path)
finally:
    os.umask(old_umask)
```

## Step 4: `migrate.py`

Manages the agent Chrome profile (isolated copy of personal Chrome, rsync'd, caches excluded):

```python
import os, shutil, subprocess
from pathlib import Path

PROJECT_ROOT = Path(__file__).resolve().parent
PERSONAL_PROFILE_ROOT = Path.home() / "Library/Application Support/Google/Chrome"
PERSONAL_PROFILE = PERSONAL_PROFILE_ROOT / "Default"
AGENT_PROFILE_ROOT = PROJECT_ROOT / ".profiles"
AGENT_PROFILE = AGENT_PROFILE_ROOT / "Default"
MEMORIES_DIR = PROJECT_ROOT / ".memories"

SYNC_EXCLUDES = [
    "Singleton*", "*Lock*", "Cache*", "Code Cache*", "GPUCache*",
    "GrShaderCache*", "ShaderCache*", "Crashpad*", "BrowserMetrics*",
    "Session Storage*", "Sessions*", "Service Worker*", "ScriptCache*",
    "DawnWebGPUCache*", "Local Storage*",
]

def _rsync_update(src, dest):
    if not src.exists():
        return
    dest.mkdir(parents=True, exist_ok=True)
    cmd = ["rsync", "-a", "--update", "--delete"]
    for p in SYNC_EXCLUDES:
        cmd.extend(["--exclude", p])
    cmd.extend([str(src) + "/", str(dest) + "/"])
    subprocess.run(cmd, check=True)

def ensure_agent_profile():
    if AGENT_PROFILE.exists():
        return str(AGENT_PROFILE.parent)
    _rsync_update(PERSONAL_PROFILE, AGENT_PROFILE)
    return str(AGENT_PROFILE.parent)

def sync_profiles():
    _rsync_update(PERSONAL_PROFILE, AGENT_PROFILE)
    _rsync_update(AGENT_PROFILE, PERSONAL_PROFILE)
    return str(AGENT_PROFILE.parent)

def sync_to_remote(server_ip, remote_user="root", remote_path="/opt/unibrowse"):
    targets = [
        (".profiles/", f"{remote_path}/.profiles/"),
        (".memories/", f"{remote_path}/.memories/"),
        ("browser-harness/agent-workspace/", f"{remote_path}/browser-harness/agent-workspace/"),
    ]
    success = True
    for local_sub, remote_sub in targets:
        local_src = str(PROJECT_ROOT / local_sub)
        if not os.path.exists(local_src):
            continue
        cmd = ["rsync", "-avz", "--delete", "--update"]
        for p in SYNC_EXCLUDES:
            cmd.extend(["--exclude", p])
        cmd.extend([local_src, f"{remote_user}@{server_ip}:{remote_sub}"])
        try:
            subprocess.run(cmd, check=True)
        except Exception as e:
            print(f"Remote sync failed: {e}")
            success = False
    return success
```

## Step 5: `setup-harness-opencode.sh`

Bootstraps `.opencode-harness/` — isolated XDG config/data dirs, copies auth files from global OpenCode, writes bin wrappers. **Run this once after setup and re-run after any global auth change.**

Key things it does:
1. Writes `opencode.json` with `google/gemini-3-flash` as default model + all Antigravity model definitions
2. Copies `antigravity.json`, `antigravity-accounts.json`, `claude-mem.js` from `~/.config/opencode/`
3. Writes `.opencode-harness/bin/opencode` wrapper (sets `XDG_CONFIG_HOME` + `XDG_DATA_HOME`)
4. Writes `.opencode-harness/bin/browser-harness` wrapper (sets `PYTHONPATH`)
5. Runs `npm install` for `@opencode-ai/plugin` dependency

After running setup, **manually create the auth.json symlink**:

```bash
ln -s ~/.local/share/opencode/auth.json \
      .opencode-harness/data/opencode/auth.json
```

**This symlink is critical.** Without it, the `opencode-antigravity-auth` plugin's `isOAuthAuth()` returns false, fetch interception is skipped, and every Gemini call goes directly to `generativelanguage.googleapis.com/v1beta` — which fails with `models/gemini-3-flash is not found for API version v1beta`.

## Step 6: `opencode.json` (inside `.opencode-harness/config/opencode/`)

Key fields:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "google/gemini-3-flash",
  "small_model": "google/gemini-3-flash",
  "compaction": { "auto": true },
  "agent": { "compaction": { "model": "opencode/big-pickle" } },
  "permission": { "*": "allow" },
  "plugin": [
    "opencode-antigravity-auth@latest",
    "/absolute/path/to/.opencode-harness/config/opencode/plugins/claude-mem.js"
  ]
}
```

**Do NOT include `oh-my-openagent` plugin.** It adds overhead with no benefit for this use case.

Model definitions to include under `provider.google.models`:
- `gemini-3-flash` — Auto-balanced, variants: minimal/low/medium/high (thinkingLevel)
- `antigravity-gemini-3-flash` — same variants, routes through antigravity proxy
- `antigravity-gemini-3-pro` — variants: low/high
- `antigravity-claude-sonnet-4-6` — no variants
- `antigravity-claude-opus-4-6-thinking` — variants: low (budget 8192) / max (budget 32768)

Under `provider.opencode.models`:
- `big-pickle` — 2M context, attachment support, variant: thinking (thinkingLevel: high)

## Step 7: `app.py` — Key Architecture Points

### Environment isolation (`agent_env()`)

Every subprocess (opencode, browser-harness) runs with:

```python
env["BU_CDP_URL"] = "http://127.0.0.1:9223"
env["BH_NO_ACTIVATE"] = "1"          # stealth: never focus Chrome window
env["BU_NAME"] = "unibrowse"         # daemon socket: /tmp/bu-unibrowse.sock
env["BH_AGENT_WORKSPACE"] = AGENT_WORKSPACE
env["CLAUDE_MEM_DATA_DIR"] = MEMORIES_DIR
env["XDG_CONFIG_HOME"] = ".opencode-harness/config"
env["XDG_DATA_HOME"] = ".opencode-harness/data"
# Prepend .opencode-harness/bin to PATH so wrappers take precedence
env["PATH"] = f"{harness_bin}:{env['PATH']}"
```

### Default model/variant

```python
DEFAULT_MODEL = os.environ.get("UNIBROWSE_MODEL", "google/gemini-3-flash")
DEFAULT_VARIANT = os.environ.get("UNIBROWSE_VARIANT", "minimal")
```

**`minimal` variant is required.** Without it, Gemini 3 Flash defaults to `thinkingLevel: "low"` which makes every response slow. `minimal` thinking is fast and sufficient for most browser tasks.

### Task dispatch

- Prefix `bh:` → raw browser-harness Python snippet (`browser-harness -c <code>`)
- Prefix `url:` → `new_tab(url); wait_for_load(); print(page_info())`
- Otherwise → `opencode run <prompt> --model <model> --variant <variant>`

### Prompt layers (for natural language tasks)

1. `browser_agent_prompt.md` (global instructions from agent-workspace)
2. `user_card.md` (persistent personal info)
3. Dynamic site context (queries local claude-mem HTTP API for site-specific fixes)
4. Runtime state (tab list, active tab, screenshot path, CDP URL)
5. User task

### Live observation loop

During task execution: polls screenshot every 3s via daemon IPC, updates sidebar `QLabel`.

### IPC (daemon client)

```python
connection, token = ipc.connect("unibrowse", timeout=10)
result = ipc.request(connection, token, {"method": "Page.captureScreenshot", ...})
```

The daemon runs at `/tmp/bu-unibrowse.sock`. Start it with:

```bash
BU_NAME=unibrowse browser-harness --daemon
```

### Post-task reflection

After each successful task, a background subprocess runs an OpenCode prompt that:
- Stores site-specific learnings via `store_learning('site_fix', ...)`
- Updates `user_card.md` with new user facts
- Calls `cleanup_tabs()` if browser is cluttered

## Step 8: Daemon Lifecycle

**Always use `BU_NAME=unibrowse`** on every browser-harness command. Without it, a differently-named daemon is created and the app can't connect.

```bash
# Kill any stale daemons first
pkill -9 -f "browser_harness.daemon" 2>/dev/null || true

# Start fresh
BU_NAME=unibrowse browser-harness --daemon

# If Chrome restarted and daemon has stale WebSocket
BU_NAME=unibrowse browser-harness --reload
```

Chrome must be launched with `--remote-debugging-port=9223`. The app does this automatically on startup if no existing backend is found.

## Common Failure Modes & Fixes

| Symptom | Cause | Fix |
|---|---|---|
| `models/gemini-3-flash is not found for API version v1beta` | `auth.json` missing in harness data dir → plugin skips fetch interception | `ln -s ~/.local/share/opencode/auth.json .opencode-harness/data/opencode/auth.json` |
| Every Gemini response takes 30-60s | Default variant is `""` → `thinkingLevel: "low"` | Set `DEFAULT_VARIANT = "minimal"` in app.py |
| `RuntimeError: listening on /tmp/bu-unibrowse.sock` | Old daemon still running | `pkill -9 -f "browser_harness.daemon"` |
| Daemon creates `about:blank` tab on startup | No real pages found; daemon auto-creates one | Normal behavior; close the blank tab |
| `ModuleNotFoundError: keyring` | Wrong Python version (3.14 instead of 3.11) | Use `launch.sh` which hardcodes pyenv 3.11.11 |
| Multiple blank tabs keep appearing | Orphaned daemon processes from previous sessions | `pkill -9 -f "browser_harness.daemon"` before launching |
| Push to `browser-use/browser-harness` returns 403 | Not a contributor | Fork to your own account: `gh repo fork browser-use/browser-harness` |
